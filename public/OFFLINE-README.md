# Offline archive

This archive uses clean routes and root-relative assets. Serve this folder as the web root.

1. Install Node.js if it is not already available.
2. Open a terminal in this folder.
3. Run `node serve.js`.
4. Open `http://127.0.0.1:8080/`.

Review `legend-vault.json` before relying on the archive. A `partial` label means one or more dependencies or limits prevented a complete offline capture.
Hosted Framer forms are disabled intentionally and must be connected to an owned backend.
